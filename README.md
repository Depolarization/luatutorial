# luatutorial —— Lua 实战教程系列

一系列围绕 **Lua** 的实战教程。每一章是一个独立、可运行的专题，配有源码、可复现的构建脚本，以及一段讲解视频。
所有代码均经过实测，不只有「能跑的片段」，更有对照校验与踩坑记录。

## 适合谁

- 在用 Lua 5.1 / 5.2（含 AndroLua、OpenResty 早期版本、某些游戏 MOD 环境）做底层数值的人；
- 想搞清楚「为什么 64 位整数在 Lua 里是个难题」的人；
- 想看「确定性网页渲染 + 配音 + 逐帧录制」怎么做技术讲解视频的人（第一章附带完整生产线）。

## 约定

- 每章目录各自独立，依赖与复现命令写在各章的 `README.md` 里。
- 视频与封面随章节提交，方便直接预览；构建脚本生成的中间产物（音频、帧列表等）不入库。
