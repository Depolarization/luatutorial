# 用两个 32 位整数，拼出 64 位整数

本仓库是 B 站视频《用两个 32 位整数，拼出 64 位整数》的**配套源码托管**，仅存放讲解中涉及的核心 Lua 代码。

## 源码

本仓库只作为该视频讲解的源码附件；所有代码以 Lua 5.1 / 5.2 为目标环境（只有 `double` 与 32 位 `bit32`）。

| 文件 | 说明 |
| --- | --- |
| `src/int64.lua` | 核心库：用高 32 位 `hi` 和低 32 位 `lo` 表示 64 位整数，含加、减、乘、除、位运算、移位、转字符串 |
| `src/bit32_pure.lua` | 纯算术实现的 `bit32` 兼容层（Lua 5.1 没有 `bit32` 时可用） |
| `src/demo.lua` | 演示脚本 |
| `src/test.lua` + `src/vectors.lua` | 与 Python 大整数对照的自检（330 组随机算例） |

视频讲解请见 B 站（搜索标题或查看视频简介中的链接）。
